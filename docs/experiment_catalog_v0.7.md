# CommLab-OFDM Experiment Catalog — v0.7

Total experiment scripts (excluding suite runners): **39**.

## v0.7 experiments

- `memory_polynomial_dpd.py` — Nonlinear PA with memory and offline indirect-learning memory DPD.
- `ici_aware_equalization.py` — Explicit Doppler ICI matrix; one-tap vs banded/full LMMSE.
- `mimo_lmmse_estimation.py` — 2x2 orthogonal-training LS versus scalar-prior LMMSE shrinkage.
- `mimo_pilot_efficiency.py` — Two-slot full training versus one-symbol frequency-orthogonal finite-CIR MIMO pilots.
- `mimo_ml_detection.py` — 2x2 QPSK ZF/MMSE versus exhaustive maximum-likelihood detection.
- `otfs_iterative_detection.py` — Sparse effective-channel CG-LMMSE OTFS detection trade-off.
- `ber_confidence_intervals.py` — Sequential QPSK BER simulation with 95% Wilson confidence intervals.
- `frequency_selective_iq.py` — Frequency-selective direct/image FIR IQ estimation and mirror-pair compensation.
