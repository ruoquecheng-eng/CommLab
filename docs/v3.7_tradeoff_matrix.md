# v3.7 Trade-off Matrix

| Mechanism | Helps with | Does not solve | Main cost / failure region |
|---|---|---|---|
| Nominal recorded propensity | Current logging metadata | Incorrect instrumentation; hidden cue | Can look exact while omitting a decision variable |
| Updated full propensity model | Observable policy drift | Hidden confounding | Same-sample nuisance reuse; larger learned weights |
| Cross-fitted propensity | Separates each prediction from its own outcome fold | Missing variables; poor overlap | Less training data per fold; can worsen finite-sample weights |
| Misspecified compact model | Low variance in simple regimes | Nonlinear time drift and interactions | Persistent calibration and OPE bias |
| Odds-envelope sensitivity | Makes assumption dependence visible | Sharp identification or causal coverage | Interval width grows rapidly with gamma |
| Sensitivity-guard selection | Avoids some confounded point choices | Productive improvement under weak evidence | Can freeze at baseline indefinitely |

## Release interpretation

The preferred output is not one universally best propensity mode. It is a structured audit:

1. compare any recorded value with an independently fitted observed-feature model;
2. measure overlap and importance-weight concentration;
3. sweep plausible odds perturbations;
4. report how selection changes under fallback;
5. stop at partial identification when the logging mechanism depends on unavailable causes.
