# v1.5 Trade-off Matrix

| Branch | Improvement lever | Benefit | Explicit cost / failure mode |
|---|---|---|---|
| Cell-Free CSI | More quantization bits | Lower CSI NMSE, better precoding | Linear fronthaul growth |
| Cell-Free clustering | More APs/user | Better cell-edge macro-diversity | More AP-user CSI links |
| CSI aging | Faster updates | Fresher precoder CSI | Higher fronthaul update load |
| Robust RIS | More uncertainty samples | Better high-uncertainty held-out rate | More optimization work; may not help at low uncertainty |
| Short packets | FBL-aware MCS | Lower short-block error | More conservative MCS |
| Short packets + OLLA | ACK/NACK calibration | Corrects SNR bias near target BLER | Adaptation transient / lower selected MCS |
| ISAC sensing budget | More sensing time | Lower angle uncertainty | Less communication payload time |
| ISAC aperture | More active elements | Higher peak gain | Narrower beam, less uncertainty tolerance |
