# v3.6 Offline-Evaluation Trade-off Matrix

| Choice | Benefit | Cost / boundary |
|---|---|---|
| More randomized logging | Better overlap, smaller weights, larger effective sample | More non-default actions on noncritical tasks |
| Deterministic logging | Operational simplicity | Target-policy value can be unidentifiable regardless of log size |
| Direct model | Low variance | Can be confidently biased and extrapolate outside support |
| IPS/SNIPS | Less outcome-model dependence | Rare actions create extreme weights |
| Doubly robust | Combines model and propensity correction | Neither component repairs zero support |
| Weight clipping | Suppresses rare-weight variance | Introduces target-dependent bias |
| Full history | More nominal samples | Under drift it estimates a historical mixture, not current value |
| Short recent window | Better temporal match | Higher sampling variance |
| Greedy policy choice | Can exploit estimated gains | Selection error at small sample size |
| Conservative fallback | Limits unproven changes | Can freeze indefinitely and forgo real improvements |

The central rule is that estimator sophistication cannot compensate for missing action support or an incorrectly defined temporal estimand.
