# v3.4 Trade-off Matrix

| Mechanism | Helps when | Cost / failure region |
| --- | --- | --- |
| Point-greedy | forecasts remain calibrated or budget is extremely scarce | under-protects after drift |
| Static guard | deployment mismatch is stable | fixed conservatism cannot track changing drift |
| Global risk debt | broad system-wide miss rises | frequent routine tasks can consume the feedback signal and bucket |
| Localized risk debt | critical classes need distinct targets | class gates are heuristic and can waste scarce budget |
| High adaptation gain | abrupt persistent shift | noise chasing, higher spend, more action switching |
| Low feedback delay | outcomes are informative and stable | immediate Bernoulli feedback can be noisy |
| Tight requested target | enough independent resilience exists | infeasible targets can cause over-protection and worse outcomes |
| Radio duplication | access paths are diverse | correlation removes marginal value |
| Cross-domain replica | edge failure dominates | consumes compute and cannot repair radio outage |

No row is a global recommendation. The v3.4 experiments deliberately include crossovers and counterexamples.
