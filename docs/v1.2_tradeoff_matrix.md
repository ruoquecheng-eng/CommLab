# CommLab v1.2 Trade-off Matrix

| Branch | Higher-cost / richer method | Simpler baseline | Main benefit | Main cost / limitation |
|---|---|---|---|---|
| RIS | continuous / multi-bit phase alignment | random or 1-bit phases | coherent cascaded gain | control resolution and unmodeled hardware/path loss |
| MU-MIMO | semi-orthogonal user selection | strongest-norm selection | better spatial conditioning before ZF | user-search complexity and instantaneous CSI need |
| DOA | MDL + MUSIC | fixed source count / Bartlett | model-order awareness and super-resolution | covariance snapshots, source-count failures at low SNR |
| Tracking | Kalman + gated NN association | raw detections | lower RMSE and continuity through misses | identity fragmentation / clutter tentative tracks |
| Hybrid MIMO | OMP subspace approximation | one-shot DFT beam selection | higher rate for same RF-chain budget | iterative beam search and idealized phase-only dictionary |
