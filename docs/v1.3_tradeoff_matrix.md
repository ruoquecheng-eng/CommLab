# CommLab v1.3 Trade-off Matrix

| Branch | Improves | Costs / risks | v1.3 evidence |
|---|---|---|---|
| More Cell-Free APs per user | Cell-edge rate, fairness, macro-diversity | More AP-user coordination/fronthaul links | 5%-tile rate `0.345 -> 1.278`; links `8 -> 192` |
| Max-min power control | Worst-user rate, fairness | Lower mean/sum rate | UC-4 min rate `0.873 -> 1.286`; mean `2.126 -> 1.286` |
| More RIS phase bits | MU sum rate | Control resolution / search size | 1-bit `4.52`, 2-bit `5.10`, 3-bit `5.32` |
| Predictive beam tracking | Alignment during sparse sensing | Motion-model mismatch can hurt | CV `2.489` vs reactive `2.996`; CA `3.981` |
| Larger active aperture | Peak array gain | Narrower beam / greater pointing sensitivity | Optimal aperture shrinks `64 -> 8` as angle uncertainty grows |
