# v2.8 State-Aware Runtime Architecture

```text
                   ┌─────────────────────────────────────┐
                   │        Runtime State Plane          │
                   │ model age / cache version / debt    │
                   │ queue backlog / twin sync error     │
                   └─────────────────┬───────────────────┘
                                     │
        ┌────────────────────────────┼────────────────────────────┐
        │                            │                            │
        v                            v                            v
 FL Downlink Recovery        Edge Model Runtime          Progressive Inference
 delta + ACK state           cache + model version       admission + completion
 selective repair            refresh budget              deadline/backpressure
        │                            │                            │
        └───────────────┬────────────┴────────────┬───────────────┘
                        │                         │
                        v                         v
             Long-Horizon FL Orchestration   Digital Twin Sync
             utility/carbon/virtual debt      predictor/error/AoII
                        │                         │
                        └───────────┬─────────────┘
                                    v
                        Communication Resource Use
```

The architectural change in v2.8 is that **state itself is a first-class simulation object**. A controller sees more than instantaneous SNR: it can act on model version age, participation debt, queue congestion, or twin prediction error. This permits experiments in which the same physical communication opportunity has different value depending on system history.
