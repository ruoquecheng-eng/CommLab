# Experiment Catalog — v3.4

1. `v34_drift_adaptation.py`: drift sweep across point, fixed guard, global/local feedback, and probability oracle.
2. `v34_localized_risk.py`: budget crossover and routine/important/critical class outcomes.
3. `v34_feedback_delay.py`: delayed outcome feedback, early recovery, activity, and the noise-damping counterexample.
4. `v34_adaptation_gain.py`: stale-to-noisy controller-gain sweep.
5. `v34_target_frontier.py`: requested target, actual risk, resource use, and infeasibility.
6. `v34_correlation_reallocation.py`: duplication-to-replica shift as radio diversity disappears.

Each experiment writes one `results/data/v34_*.csv` file and two `results/figures/v34_*.png` figures. All v3.3 and earlier result artifacts remain in the release tree.
