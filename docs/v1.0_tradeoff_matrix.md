# CommLab v1.0 — Experiment Trade-off Matrix

| Research question | Baselines / methods | Main measured axes | Key caution |
|---|---|---|---|
| How should retransmissions spend radio resources? | Chase repetition vs LDPC incremental redundancy | packet success, coded bits, rounds, goodput | custom mother code/rate matching |
| How much does MIMO soft-information quality matter to an iterative code? | K-best list LLR vs exact max-log | BER, FER, Min-Sum iterations | small 2x2 QPSK |
| What does OTFS grid mismatch cost? | integer-grid coarse support vs local Doppler refinement | Doppler MAE, pilot residual | correct coarse delays assumed |
| Can ACK/NACK correct biased link-quality estimates? | open-loop MCS vs OLLA | BLER, goodput, MCS, SNR offset | synthetic BLER curves |
| Can a communication OFDM grid sense targets? | 2-D range-Doppler processing | range, velocity, resolution | normalized monostatic model |
| Can target detection be automatic rather than top-K peak picking? | CA-CFAR | detection probability, false alarms | no clutter/fluctuating target model |
| How do multiple receiver impairments interact? | staged timing/CFO/IQ/CPE processing | BER, EVM | no multipath in this stress case |
| How much Doppler coupling invalidates one-tap OFDM? | one-tap, banded LMMSE, full/CG ICI | BER, ICI energy, iterations | block-stationary channel model |
| How does MIMO search complexity buy performance? | MMSE, K-best, ML | BER, tree expansions | pedagogical non-optimized implementation |
| How does RF model mismatch matter? | memory polynomial vs cross-memory GMP | NMSE, EVM, spectral leakage | synthetic PA models |
| Throughput or fairness/latency? | max-rate, PF, delay-PF | sum rate, Jain fairness, delay, backlog | abstract MAC service model |
| What does short blocklength cost? | Shannon vs normal approximation | achievable rate vs n/epsilon | fundamental-limit approximation only |

## Recommended portfolio narrative

Do not present the repository as dozens of unrelated features. Use five connected layers:

1. **Waveform and receiver:** OFDM, synchronization, estimation, ICI.
2. **Reliability and spatial processing:** MIMO, soft detection, coding, HARQ.
3. **Realistic RF/high mobility:** phase noise, SCO/IQ, PA/DPD, OTFS.
4. **System decisions:** link adaptation, scheduling, queues, finite blocklength.
5. **New v1.0 extension:** reuse the communication waveform for sensing/ISAC.
