# v1.6 Trade-off Matrix

| Branch | Improvement lever | Benefit | Explicit cost / failure mode |
|---|---|---|---|
| RIS CSI precision | More CSI bits | Better phase-control decisions | Linear CSI payload growth; gains saturate around 4-6 bits in current experiment |
| RIS robustness | Optimize over predicted ensemble | Can improve lower-tail utility | More computation; can reduce mean rate under severe aging/model mismatch |
| HARQ | More retransmission evidence | Fewer drops / better reliability | Extra channel uses, attempts and delay |
| OLLA | ACK/NACK calibration | Lower NACK under SNR bias | More conservative MCS can reduce goodput |
| Predictive sensing | Look ahead to future uncertainty | Reduces myopic under-sensing | Higher sensing overhead; shallow lookahead remains suboptimal |
| CSI refresh | More frequent updates | Fresher precoder CSI | Higher fronthaul power |
| AP activation | More active APs | Higher macro-diversity / rate | More circuit power and CSI links |
| CSI quantization | More bits/component | Lower quantization distortion | Higher transport energy and payload |
