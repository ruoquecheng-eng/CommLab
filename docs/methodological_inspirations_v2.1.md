# Methodological Inspirations — v2.1

v2.1 borrows **research questions and experiment structure, not source code**, from several active 2026 themes:

- communication-efficient wireless FL where over-the-air aggregation and client selection must be designed jointly;
- non-IID FL client selection balancing data contribution, communication/resource quality, and participation fairness;
- multi-task semantic communication where one compact representation may need to support heterogeneous downstream tasks;
- robust RIS/AirComp design under imperfect CSI;
- distributed / Cell-Free receive cooperation for computation-oriented links.

Representative public references consulted while selecting v2.1 directions include:

- Thabet et al., “Toward efficient wireless federated learning via decoupling over-the-air model aggregation and client selection,” IEEE Internet of Things Journal, 2026, DOI 10.1109/JIOT.2026.3662612.
- “FedDCS: Communication-efficient federated learning with dynamic client selection,” Information Sciences, 2026, DOI 10.1016/j.ins.2026.124068.
- Su et al., “Fair client selection for multi-task federated learning in mobile edge networks,” Information Processing & Management, 2026, DOI 10.1016/j.ipm.2026.104748.
- Shi, Zhang and Xu, “Multitask Semantic Communications for Edge Intelligence Network,” IEEE Wireless Communications Letters, 2026, DOI 10.1109/LWC.2026.3711560.
- Pan et al., “Robust Design for STAR-RIS Assisted Over-the-Air Computation Systems With Imperfect CSI,” IEEE Wireless Communications Letters, 2026, DOI 10.1109/LWC.2026.3651435.

CommLab deliberately keeps the implementations small and transparent so selection bias, task conflict, uncertainty, and resource cost can be inspected directly.
