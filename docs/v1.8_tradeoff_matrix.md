# CommLab v1.8 Trade-off Matrix

| Branch | Resource / design knob | Benefit | Cost / failure mode |
|---|---|---|---|
| Joint Cell-Free CSI | AP refresh choice + bits/AP | Lower CSI NMSE and better edge rate under a fixed budget | Integer/greedy baseline; low-value refreshes can add quantization noise |
| Deadline HARQ | PF vs EDF vs risk score | Timely completion / reliability | EDF may sacrifice goodput; risk score is heuristic |
| AoI | age vs channel vs reliability priority | Fresher status information | Throughput-optimal/max-SNR scheduling can starve users |
| AoI + Chase | retransmit old sample vs send fresh | Higher decode reliability | Successful old packets may reset AoI less aggressively |
| Event RIS | trigger threshold / max control age | Adaptive control overhead | Requires probe/utility observation; threshold tuning |
| Budgeted ISAC | long-term sensing ceiling | Concentrates sensing during maneuvers | Lower budgets increase posterior uncertainty |
| Grant-free NOMA | power spread + SIC | More decoded collisions at high offered load | Requires power separability and ideal cancellation in this baseline |
