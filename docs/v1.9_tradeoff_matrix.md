# CommLab v1.9 Trade-off Matrix

| Branch | Resource / decision | Benefit | Cost / failure mode |
|---|---|---|---|
| IRSA | repetition degree + iterative SIC | resolves collisions and increases random-access throughput | more replicas consume energy; above graph threshold unresolved collisions dominate |
| AirComp | simultaneous analog aggregation | one shared channel use for many devices | weakest-user inversion, noise amplification, synchronization sensitivity |
| Truncated AirComp | channel threshold | suppresses deep-fade inversion noise | drops weak devices and introduces aggregation/subsampling error |
| URLLC reservation | fixed reserved PRBs | deterministic URLLC capacity | idle reservation wastes eMBB spectrum at light load |
| URLLC preemption | puncture eMBB when URLLC arrives | strong deadline protection with no idle reservation | eMBB throughput falls as URLLC load increases |
| Adaptive reservation | forecast-based reserve | can reduce permanent over-reservation | burst underprediction misses deadlines; overprediction wastes PRBs |
| Energy-harvesting AoI | scheduling + finite battery | fresh status under energy scarcity | energy outage, battery overflow and user starvation |
| Max-SNR status policy | exploit best channel | high successful-delivery count | poor fairness / very stale weak-user information |
