# v1.4 Trade-off Matrix

| Branch | More aggressive choice | Benefit | Cost / failure mode |
|---|---|---|---|
| Pilot reuse | Fewer orthogonal pilots | Lower pilot overhead | More contamination and channel-estimation error |
| Pilot assignment | Contamination-aware reuse | Lower co-pilot overlap / better cell-edge rate | Greedy computation and no global-optimum guarantee |
| Cell-Free RIS | Sum-rate objective | Higher aggregate rate | Slightly weaker worst-user protection |
| Cell-Free RIS | Min-rate objective | Better weakest-user rate | Lower total rate |
| OLLA | Larger SNR backoff after NACKs | Lower BLER/NACK rate | More conservative MCS if over-tuned |
| HARQ | More retransmission attempts | Higher delivery probability | Radio-resource use and delay |
| Delay-PF | Strong HOL-delay boost | Lower tail delay under backlog | Can reduce opportunistic rate gain |
| ISAC beam | Communication-heavy weight | Higher communication rate | Lower sensing gain |
| ISAC beam | Sensing-heavy weight | Stronger target-direction illumination | Communication-rate loss |
| Active AP count | More active APs | Better coverage / user rate | Higher circuit/coordination power |
| Coverage-aware AP selection | Protect weak geometry | Better sparse-set edge coverage | Can reduce average rate / energy efficiency |
