# v2.0 Trade-off Matrix

| Branch | Gain | Cost / failure mode |
|---|---|---|
| AirComp-FL | one shared aggregation resource per round | fading/noise directly perturb optimization |
| Truncated AirComp | suppresses weakest-fade noise | drops clients and can bias/noisify learning |
| RIS max-min AirComp | improves weakest effective channel | objective differs from conventional sum-gain design; passive-control overhead |
| Cell-Free AirComp | spatial diversity improves bottleneck | perfect distributed coherence/CSI assumption; centralized sample transport |
| Task-oriented communication | large channel-use reduction for a known task | loses nuisance/source information and reconstruction quality |
| Capture-aware IRSA | additional packets decoded from collisions | needs power-domain separability; overload threshold remains |
