## v2.0 design principle

The platform distinguishes **what must be reconstructed** from **what the application actually needs**. Packet communication aims for symbol/bit recovery; AirComp deliberately exploits waveform superposition to recover an aggregate; task-oriented transmission may discard source components that are irrelevant to the downstream decision.

## Current abstraction boundaries

- AirComp assumes analog synchronization and normalized power control.
- Federated learning uses convex linear regression so aggregation error remains inspectable.
- RIS-AirComp uses finite-bit coordinate ascent, not global nonconvex optimization.
- Cell-Free AirComp assumes coherent central combining and perfect CSI.
- Task-oriented communication uses a known Gaussian sufficient statistic, not a neural semantic encoder.
- Capture-IRSA assumes perfect replica pointers and cancellation after a successful capture.
