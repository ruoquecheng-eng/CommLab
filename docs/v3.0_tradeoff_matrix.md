# v3.0 Trade-off Matrix

| Question | Compared methods | Primary metrics | Main caution |
|---|---|---|---|
| Protect average control or rare bad events? | mean-value vs risk-value | mean, P95, CVaR95 cost | empirical heuristic, not optimal risk-sensitive control |
| How many state bits should be sent? | fixed 3-bit, fixed 10-bit, adaptive 3/6/10 | control cost, payload, success | scalar predictive quantization abstraction |
| Fastest edge or safest edge? | latency-only, trust-aware, risk-aware | latency, failure, deadline miss, energy | synthetic node reliability |
| Cache locally or route globally? | nearest, cache-first, joint | latency, hit rate, backhaul, load balance | simple finite-cache heuristic |
| Refresh largest local error or largest system value? | max-age, local-error, system-value | system cost, formation error, age | coupled scalar-chain model |
