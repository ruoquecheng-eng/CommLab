# Methodological Inspirations — v3.0

v3.0 borrows problem structure, not source implementation, from current work on risk/reliability-aware cyber-physical and edge orchestration.

- Future Generation Computer Systems (2026/2027 issue), *AI-driven Autonomous Digital Twin Orchestration for Industrial Cyber-Physical Systems using edge intelligence and federated coordination*: motivates multi-objective latency/energy/queue/reliability orchestration.
  https://www.sciencedirect.com/science/article/pii/S0167739X26003365
- Physical Communication (2026), *Federated graph reinforcement learning for joint caching and inference offloading in edge intelligence*: motivates slow-timescale AI-asset caching coupled with fast-timescale inference routing.
  https://www.sciencedirect.com/science/article/pii/S1874490726002429
- Internet of Things (2026), *HAR-SemCom: Verifiable Semantic Communications for HAR with Task-Fidelity Guarantees and Few-Shot Personalization at the IoT Edge*: motivates task-fidelity-aware variable communication resources rather than source fidelity alone.
  https://www.sciencedirect.com/science/article/pii/S254266052600212X

CommLab deliberately uses transparent model-based/heuristic baselines rather than reproducing the cited learned controllers.
