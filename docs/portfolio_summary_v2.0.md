# Portfolio Summary — CommLab v2.0

## Recommended positioning

**CommLab — Wireless Communication Systems Laboratory** is a modular Python research simulator spanning OFDM/MIMO/RF/ISAC/system-level networking. v2.0 adds a new **Wireless Edge Intelligence** layer: over-the-air computation, communication-aware federated optimization, programmable propagation for computation, task-oriented transmission, and capture-aware massive random access.

## CV-style bullet
