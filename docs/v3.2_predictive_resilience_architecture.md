# v3.2 Predictive Resilience Architecture

```text
                     STATE / FORECAST LAYER
     mobility forecast   latency uncertainty   failure domains
            |                    |                    |
            v                    v                    v
     predictive migration   chance admission   replica placement
            |                    |                    |
            +---------+----------+----------+---------+
                      |                     |
                      v                     v
                EDGE RUNTIME          RADIO RELIABILITY
              migration/recovery      UEP / multi-connectivity
                                      threshold / risk budget
                      |                     |
                      +----------+----------+
                                 |
                                 v
                      TASK / CONTROL OUTCOME
                deadline, utility, outage, cost
```

v3.2 deliberately separates *state prediction* from *decision consequence*. Forecasts may be wrong; replicas may share a failure domain; mean latency may hide a deadline tail; high-fidelity packets may be harder to deliver; duplicated radio paths may be correlated; and the marginal value of an extra duplicate can collapse as correlation rises. Every v3.2 experiment therefore reports both the intended benefit and the resource/reliability cost that can invalidate a naive metric.
