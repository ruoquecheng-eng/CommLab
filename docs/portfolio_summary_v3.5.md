# CommLab v3.5 Portfolio Summary

v3.5 extends CommLab from closed-loop risk adaptation to an explicit audit of what the loop can observe. It models a practical systems paradox: the better a protection mechanism becomes at rescuing failures, the less often the controller sees evidence that the protected primary component is unhealthy.

The release contributes a paired-outcome simulator, five feedback modes, component-specific delayed risk debt, telemetry dropout, routine-only audits, a shared resilience budget, six reproducible experiments, an interactive Dashboard Lab, and automated invariants that prevent critical-task auditing or current-outcome genie information.

Its main portfolio value is methodological. It retains results where component telemetry improves radio-drift reliability, but also shows that correct attribution, faster detection, and more observations do not guarantee better cross-layer decisions. The missing ingredient can be action value, independence, or resource feasibility rather than information.
