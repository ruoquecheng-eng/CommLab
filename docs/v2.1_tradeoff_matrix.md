# CommLab v2.1 Trade-off Matrix

| Branch | Improve | Cost / failure mode | Main metric |
|---|---|---|---|
| Strong-channel FL selection | selected-link quality | non-IID participation bias | global loss, Jain fairness |
| Participation-age FL selection | client fairness / model balance | weaker selected links | fairness, weakest link, loss |
| IRSA random-access FL | decoded updates in suitable load regime | repetition overhead and peeling threshold | decoded fraction, empty rounds |
| Uncertainty-sampled RIS AirComp | moderate-CSI-error weakest-link robustness | scenario-search complexity; high-error model mismatch | weakest-device gain |
| LCB Cell-Free AirComp | aggregation tail risk | can sacrifice median performance | p90 aggregation MSE |
| Shared rank-1 semantics | one channel use for two tasks | fails when task subspaces diverge | task accuracy / channel uses |
| Shared rank-2 semantics | preserves two task statistics | doubles semantic dimension | task accuracy / channel uses |
