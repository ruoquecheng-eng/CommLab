# CommLab v3.2 Trade-off Matrix

| Research question | Baselines | Primary metrics | Failure region / crossover |
|---|---|---|---|
| When should a running service migrate before node failure? | sticky / reactive / predictive-risk | mean/P95 latency, deadline miss, migration rate, traffic | forecast error creates false migrations; around noise ~0.8–1.0 mean latency crosses above reactive |
| Are more replicas always more reliable? | popularity / criticality / diversity-risk | raw outage, task-weighted outage, domains/model, storage | replicas in one shared zone are correlated protection; diversity can beat a higher replica count |
| Should inference admission use expected latency or a tail constraint? | mean-latency / 99%-chance | admission, rejection, deadline miss, raw/on-time utility | chance reliability is purchased with rejection/local fallback; very high jitter makes it conservative |
| Should every control-state component receive equal protection? | equal repetition / critical UEP | control cost, safety violation, critical miss, fixed radio budget | UEP wins at low SNR; the advantage collapses at high SNR as delivery saturates |
| Does dual-link duplication guarantee diversity? | single / full duplicate / adaptive duplicate | packet outage, P95 delay, transmissions/packet | increasing link correlation erodes full-duplication gain |
| Where should adaptive duplication operate on the reliability-resource frontier? | adaptive threshold sweep | packet outage, transmissions/packet, duplication rate, P95 latency | aggressive duplication has diminishing returns, especially when path failures are correlated |
| Can adaptive duplication save radio resources without losing control safety? | single / full / safety-aware adaptive | safety violation, control cost, update success, tx/slot | adaptive is close to full in favorable diversity regimes but loses protection as correlation rises |
| Which semantic samples deserve retransmission? | no HARQ / channel HARQ / task HARQ | accuracy, hard-sample accuracy, tail error, channel uses | retained earlier v3.2 result: task confidence helps around difficult samples; demand falls at high SNR |
| How should control and inference share one radio? | control-first / inference-first / age-first / task-value | control cost, safety, deadline utility | retained result: single-service priorities can starve or destabilize the other service |
| Is checkpoint speculation always useful? | cold / periodic / predictive checkpoint | mean/P95 latency, traffic, cold migrations | retained negative result: simple prediction can lose to periodic checkpoints |
| Should all control-state bits go to the most critical component? | uniform-low / single-high / risk-bit allocation | cost, violation, payload | retained result: poor links favor broad coarse observability before precision concentration |
