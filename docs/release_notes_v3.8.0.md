# CommLab v3.8.0

CommLab is a local wireless-communications simulation workbench. This release keeps the existing numerical models and adds a more usable desktop experiment flow.

- Search and filter 130 labs, pin favorites, and reopen the most recently used lab.
- Submit parameters explicitly, restore defaults, and keep a local run history.
- Export run metadata and metrics as JSON/CSV and the current figure as PNG.
- Compare compatible metrics from the same lab, including signed changes in percentage points where appropriate.
- Improve local history-file recovery and concurrent saves, and tighten the mobile layout.

Download the Windows installer (`CommLab-Setup-v3.8.0-Windows-x64.exe`) or portable ZIP (`CommLab-Windows-x64.zip`). The app serves its interface on localhost. All experiments produce synthetic simulation results; this release does not claim measured wireless data or hardware validation.
