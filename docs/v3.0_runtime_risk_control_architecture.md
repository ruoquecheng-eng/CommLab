# v3.0 Runtime Risk & Control Architecture

```text
Physical / application state
        |
        +--> plant error / shock exposure ------> risk-sensitive feedback scheduler
        |
        +--> prediction innovation -------------> variable-rate state encoder
        |
        +--> inference request -----------------> edge cache + offload controller
        |
        +--> edge queue / trust / failure ------> reliability-aware orchestrator
        |
        +--> coupled multi-agent state ---------> system-value feedback scheduler

Wireless / edge resources
        |
        +--> packet success, payload size, queues, cache misses, recovery delay
        |
        v
Application objective
        +--> mean cost
        +--> CVaR / tail risk
        +--> deadline reliability
        +--> inference latency
        +--> formation / physical control cost
```

The architecture is intentionally heuristic and decomposable: v3.0 studies when conventional radio/network metrics become misaligned with application-tail and control objectives.
