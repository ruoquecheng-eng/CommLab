# v2.1 Edge-Intelligence Architecture

v2.1 organizes the Wireless Edge Intelligence branch around four coupled layers:

```text
Non-IID / Multi-task Data
        |
        +--> Client utility / participation history
        |
        v
Wireless Access and Selection
  - strongest-link / age-aware selection
  - ALOHA / IRSA update delivery
        |
        v
Computation-Oriented PHY
  - AirComp
  - RIS weakest-link shaping
  - Cell-Free receive cooperation
  - CSI uncertainty / tail-risk control
        |
        v
Downstream Objective
  - global FL loss and group balance
  - task-1/task-2 classification utility
  - communication cost and participation fairness
```

The central v2.1 principle is that a local communications metric is not automatically aligned with the downstream objective. Strong-link client selection can distort the effective data distribution; repetition random access can collapse when the graph is overloaded; robust link control can over-regularize; and one shared semantic feature can fail when task-relevant subspaces diverge.

## Evidence chain

| Branch | Communication-side metric | Downstream metric |
|---|---|---|
| Non-IID FL selection | weakest selected link | global/group loss, participation fairness |
| Random-access FL | decoded client fraction | learning loss / empty rounds |
| RIS-AirComp uncertainty | weakest effective device channel | analog aggregation robustness |
| Cell-Free CSI-risk control | projected CSI confidence | p90 aggregation MSE |
| Multi-task semantics | transmitted representation dimension | per-task accuracy |
