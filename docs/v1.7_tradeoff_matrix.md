# CommLab v1.7 Trade-off Matrix

| Study | Resource saved / optimized | Cost or failure mode | Main metric |
|---|---|---|---|
| Async CSI refresh | AP CSI update budget | stale/starved APs; edge-rate collapse | CSI NMSE, edge rate, AP age |
| Bounded uncertainty refresh | global CSI freshness | slightly worse NMSE than unconstrained uncertainty | edge rate vs NMSE |
| Predictive CSI compression | CSI distortion at fixed bits | requires a temporal channel predictor | NMSE gain vs correlation |
| IR-HARQ | retransmission efficiency | extra redundancy and delay | goodput, rounds, drops |
| Two-timescale RIS | RIS phase-control bandwidth | passive phases become stale | sum rate vs control bits/slot |
| Queue-aware ISAC | payload service under congestion | tracking uncertainty rises | backlog, delivered bits, sensing fraction |
| Predictive queue-aware ISAC | reduces myopic undersensing | added lookahead computation; not globally optimal | backlog vs posterior angle std |
