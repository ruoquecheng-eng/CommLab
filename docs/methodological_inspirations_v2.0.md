# Methodological Inspirations — v2.0

v2.0 borrows **problem structure**, not source code, from current research themes:

- over-the-air computation for communication-efficient federated/edge learning;
- RIS-assisted AirComp, where passive phases are optimized for aggregation distortion rather than ordinary point-to-point received power;
- communication-efficient edge intelligence, where convergence and communication cost are evaluated jointly;
- task-oriented / semantic communication, where task utility is distinguished from bit/source fidelity;
- random-access SIC with both graph structure and physical-layer capture.

The repository deliberately implements small transparent baselines so every assumption can be traced and tested.
