# v3.2 Reliability-Oriented Orchestration Architecture

```text
                 downstream task reliability
                           |
      +--------------------+--------------------+
      |                    |                    |
 semantic sample       physical control      edge AI service
 confidence            / safety state        state / model state
      |                    |                    |
 task-HARQ          mixed-service value      failure domains
      |              + bit allocation        + checkpoints
      |                    |                    |
      +--------------------+--------------------+
                           |
               finite wireless / storage /
                 migration resource budget
                           |
                task-level runtime metrics
     accuracy tail | safety | utility | outage | latency
```

The v3.2 design keeps the individual models deliberately transparent. The common architectural principle is that reliability is evaluated against the **downstream task**, not only packet delivery or average link quality.
