# v2.5 Trade-off Matrix

| Research question | Methods | Main metrics | Main lesson |
|---|---|---|---|
| Staleness + Byzantine clients | mean / median / conflict+decay | final loss, accepted fraction | simple robust statistics can beat a more specialized heuristic |
| Structured non-IID personalization | global / cluster / local | client test MSE | cluster sharing helps only when grouping is reliable |
| Private hardware AirComp | privacy noise + PA + ADC/AGC | median/p90 aggregation MSE | ADC gains saturate when intentional perturbation dominates |
| Real-time split inference | static / deadline / energy-aware | on-time accuracy, energy, latency | raw accuracy is insufficient under hard deadlines |
| Model downlink | common multicast / layered multicast / serial unicast | delivery time, utility proxy | layered delivery mitigates weakest-user multicast bottlenecks |
