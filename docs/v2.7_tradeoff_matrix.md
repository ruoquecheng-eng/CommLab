# CommLab v2.7 — Trade-off Matrix

| Research question | Baselines | Primary metrics | Main trade-off / caution |
|---|---|---|---|
| When should FL downlink send a full keyframe? | Fixed interval, budgeted age-trigger | model age, MSE, DL size, keyframes | fresher client state vs resynchronization airtime; compare at matched average payload |
| How should FL client selection react to carbon intensity? | Random, utility, carbon-only, balanced | excess loss, carbon proxy, Jain fairness, latency | emissions proxy vs statistical coverage/fairness; carbon-only can bias non-IID data |
| Which AI models belong in an edge cache? | Static, LRU, periodic popularity, periodic value-density | mean/P95 latency, hit rate, model-fetch backhaul, cache updates | freshness/hit rate vs churn/backhaul; hit rate alone is insufficient |
| Which progressive inference request should get the next chunk? | FIFO, EDF, value, urgency, completion-aware | on-time utility, misses, backlog, radio uses | urgency/value vs completion locality; excessive preemption can strand partial jobs |
| Which multicast misses are worth repairing? | no repair, importance repair, all repair | weighted utility, coverage, airtime ratio | application value vs weak-user airtime; full repair can exceed common broadcast cost |
